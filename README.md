# SPLAH Roblox News Bot

Автоматически отслеживает @Roblox и @Bloxy_News и отправляет новые публикации в Discord.

## Railway
Добавь в Variables только `DISCORD_TOKEN` — настоящий токен бота. Railway запускает `python main.py` автоматически.

Канал по умолчанию: `1550746194219765873`. Проверка: каждые 180 секунд.

Не публикуй настоящий Discord-токен в GitHub.
